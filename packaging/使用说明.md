# Mlog 辅助（MAI）安装与使用

这个包把两样东西打在一起，装完就能用：

| 目录 | 是什么 |
| --- | --- |
| `mod/MlogAuxiliary/` | 游戏内模组：F3 框选、描述框、作业面板、写入与撤销、聊天框播报 |
| `mod/MlogAuxiliary/sidecar/` | 本机的逻辑后端：静态检查、模板组装、调用大模型。`bin/logicd.exe` 是打好包的独立程序，**不需要装 Python** |

模组只负责界面和写入，真正读代码、查错误、找模型的是 sidecar。两个都要在。

## 一、装（两步）

1. **解压到一个有写权限的目录**，比如 `桌面\MAI-0.13.1`。
   不要放在 `Program Files` 下面——sidecar 要往包里的 `out\` 写作业记录，没权限会失败。
2. **双击 `安装.bat`**。它会自己找 Mindustry 的 `saves\mods`（Steam 版和 `%APPDATA%\Mindustry` 版都试），
   把模组连同 `sidecar\bin\logicd.exe` 一起拷进去、按 `VERSION.txt` 里的 SHA256 逐字节核对，
   旧版本会备份成 `MlogAuxiliary.bak-<时间>`。找不到就让你手动粘路径。

然后**重启游戏**（模组是启动时加载的，热重载不一定干净）。

**没有第三步。** 后端不用你自己开窗口：第一次按 F3（或打开面板）时，模组先探
`http://127.0.0.1:8765/health`，探不到就把随包的 `logicd.exe` 拉起来，再轮询到它开口，
屏幕上会依次出现「正在启动 sidecar…」和「sidecar 已就绪」。

`启动逻辑后端.bat` 还留着，但只在两种情况下用：想手动看后端日志、或者这是个没有 exe 的源码检出。
它优先跑随包的 exe，没有 exe 才退回 Python。

### 也可以在游戏里直接导入

包旁边还有一个 `MAI-<版本>-mod.zip`，那个是给游戏内 **模组 → 导入** 用的：只含模组本体（含 `sidecar/bin/logicd.exe`），
根目录就是 `MlogAuxiliary/`，游戏能认出 `mod.hjson`。

- 导入时选 **带 `-mod` 的那个**。
- 不要选整个安装包（`MAI-<版本>.zip`）：它根目录下有 `mod/`、`安装.bat` 等多项，游戏的导入只看 zip 根，
  读不到 `mod.hjson`，会报「没有检测到 mod.hjson」。
- 游戏内导入后同样**重启游戏**；`安装.bat` 和游戏内导入选一个就行，别都做（后做的会覆盖前一份，旧的备份成 `.bak-<时间>`）。

## 二、第一次用

1. 游戏里 **设置 → Mlog辅助**：填三样
   - 地址：模型服务的 base url（`http://.../v1` 这种，sidecar 会自动补 `/chat/completions`）
   - 密钥：你的 API key（只存在本机 `Core.settings` 和 sidecar 进程内存里）
   - 模型：模型名
   点「测试连接」，看到回话就通了。**每次重启 sidecar 后，模组会自动把这三样再推一遍**，不用重填。
2. 游戏里 **按 F3** 框选要处理的处理器 → 松手弹描述框 → 写一句话（比如「容器里铜够 120 就打印到 message1」）→ 确认。
   框里每台处理器各投一个作业，框右下角出现进度徽标。
3. 点徽标打开**作业管理窗**：看每台的状态、模型的思考过程、静态检查结论。
4. 静态检查全过才允许写入；写入前会做冲突检测（投递作业之后你手动改过代码或链接表，会先拒绝一次）。
   写错了点面板上的「撤销」，或者整批事务撤销。

联机时状态会播报到聊天框，格式 `MAI[逻辑] Generating (12,34): ...`；单机没有聊天框，走屏幕左下角的淡出提示。

## 三、出问题看这里

| 现象 | 原因 / 怎么办 |
| --- | --- |
| 面板说连不上 sidecar | 先看 `saves\mods\MlogAuxiliary\sidecar\bin\sidecar.log`（模组拉起的后端把输出写在这里）；源码检出则用 `启动逻辑后端.bat` |
| 提示「这个安装里也没有 sidecar/bin/logicd.exe」 | 包没装全（只拷了 `mod.hjson` 和 `scripts`）：重新双击 `安装.bat` |
| 游戏内导入报「没有检测到 mod.hjson」 | 选错了包：导入要选 `MAI-<版本>-mod.zip`（根目录是 `MlogAuxiliary/`），不是整个安装包 |
| 说 sidecar 是旧版本（`no such endpoint`） | 后端在跑但版本旧：`停止逻辑后端.bat` 再按一次 F3，模组会拉起新的 |
| 双击 `启动逻辑后端.bat` 一闪而过 | 这份包里没有 exe 且没装 Python 3；重装包，或去 python.org 装 Python |
| 端口 8765 被占 | 别的程序占着：改设置页的地址端口（模组会按地址里的端口拉起 exe），或者关掉占用者 |
| 写入后游戏里代码没变 | 联机里可能没权限：房主/管理员才能改逻辑块，模组会明说「无权限」 |
| 模型老是超时/截断 | 面板里看作业的「思考过程」和错误原因；推理模型会先想很久，预算不够时作业会自己重试一次 |

## 四、卸载

- 双击 `卸载.bat`：从 `saves\mods` 删掉 `MlogAuxiliary`（备份的 `.bak-*` 目录不动）。
- 双击 `停止逻辑后端.bat`：把还在跑的 sidecar 进程停掉（不装服务，不写注册表）。
- 整个文件夹删掉即可，sidecar 不写注册表、不装服务、不留系统级文件。
  唯一的痕迹是包里的 `out\jobs\*.json`（作业记录）和 `out\snapshots\`（写入前快照），删包一起没了。

## 五、版本

`VERSION.txt` 里是这份包里两边的版本：

```
MAI 0.13.1          <- 模组（游戏里 设置 页 / MAIDIAG 显示的版本）
sidecar 0.13.1      <- 后端（GET /health 的 version）
```

模组和 sidecar 版本号不同步是正常的：有的版本只改界面，有的只改后端。
